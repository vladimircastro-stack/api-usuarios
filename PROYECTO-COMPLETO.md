### Subir el frontend (una vez)

En PowerShell:

```powershell
gh auth login
cd C:\Users\wilma\Desktop\SGCRD\frontend
gh repo create vladimircastro-stack/VC-DistribuidorPro-frontend --public --source=. --push
```

O cree el repo vacio en github.com y ejecute:

```powershell
cd C:\Users\wilma\Desktop\SGCRD\frontend
git remote add origin https://github.com/vladimircastro-stack/VC-DistribuidorPro-frontend.git
git push -u origin main
```
